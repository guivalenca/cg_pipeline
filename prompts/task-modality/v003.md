You will read one task written for learners, with the answer it expects.

Classify the central cognitive performance the task demands. Ask where the
correctness of the answer comes from:

- `do` when answering requires working over the particular inputs supplied by
  the task to produce a result that is not simply recalled.
- `explain` when answering requires articulating knowledge the learner is
  expected to carry already; any supplied context identifies the subject but
  is not material the learner must operate on.

Judge the work needed, not the grammatical form of the response. A result can
be written as words or a list, and a request beginning with “what” can demand
either performance. If the task contains both, choose the performance that
carries the main evidence of mastery. Use `unsure` only when the task and
answer genuinely do not determine that distinction.

Use the report_modality tool once and exercise your best judgment.
