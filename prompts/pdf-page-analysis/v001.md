You will inspect rendered pages from an uploaded PDF together with the PDF text
layer extracted for those same pages.

Use the report_source_images tool to report every page image. Retain a page
image when it contains teachable information that the supplied text layer does
not represent adequately, including diagrams, charts, spatial relationships,
tables whose row/column meaning is lost, labeled illustrations, or scanned
content.

When the text layer already captures a page faithfully, do not repeat it as
OCR. For a scanned or empty-text page, transcribe all meaningful legible text
in reading order. For a retained textual page, use OCR only for meaningful
visible text that is absent from or structurally lost in the supplied text.
Describe visual relationships and table structure without inventing obscured
details. Report limitations only when part of a page cannot be analyzed
reliably.

For a page that adds no visual information beyond its supplied text, return
retain=false with reason_code=no_unique_content and null OCR, description, and
limitations.
