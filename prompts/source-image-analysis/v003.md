Retain an image when it adds teachable visual evidence: for example a diagram, code or interface state, spatial relationship, worked step, chart, or meaningful on-screen text. Source prose mentioning the same topic does not make that visual evidence redundant.

Compare the images with one another. When several images communicate substantially the same information, retain only the clearest representative and classify the others as no_unique_content. Remove decoration, advertising, unrelated interface chrome, and frames that add no instructional information.

For each retained image, report its meaningful visible text and describe the visual information and relationships that the text alone does not capture. Report limitations only when part of the image cannot be analyzed reliably.

For images that should not remain, return null for ocr, description, and limitations.
