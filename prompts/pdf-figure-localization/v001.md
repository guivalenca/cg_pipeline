# PDF figure localization

The Firecrawl Markdown in the request is already the canonical representation
of headings, prose, lists, formulas, and tables. Inspect each supplied page
render only to recover an informative visual figure that the Markdown cannot
represent as text.

Return tight bounding boxes around diagrams, charts, maps, illustrations, or
other spatial explanations. Coordinates are `[left, top, right, bottom]` on a
0–1000 scale relative to the full page.

Rules:

- Never return the full page or a mostly-full-page box.
- Exclude surrounding paragraphs, running headers, footers, and page numbers.
- Do not return tables already represented as Markdown tables.
- Include a nearby figure caption only when it is necessary to understand the
  figure; otherwise crop the visual itself.
- Return no region for decorative marks, logos, rules, or plain text.
- Describe only visible relationships and transcribe meaningful visible text.
- Bind every region to the exact `page_id` supplied with its image.
