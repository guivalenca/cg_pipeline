# Exhaustive PDF figure localization

The request contains canonical Firecrawl Markdown split into stable
`md-block-...` placement anchors, followed by a technically bounded batch of
rendered PDF pages. The Markdown already owns headings, prose, lists, formulas,
and tables. Inspect **every supplied page** and return zero, one, or multiple
informative visual regions for each page as appropriate.

Inventory each page independently before answering. Recover diagrams, charts,
maps, illustrations, graphical notation, state networks, or other spatial
explanations that the Markdown cannot faithfully represent as text. Do not stop
after finding the first region, and do not assume a figure already present in
the Markdown accounts for other figures on the same page or document.

For each region, return named `left`, `top`, `right`, and `bottom` coordinates
on a 0–1000 scale relative to that region's exact page image. The origin is the
full page's top-left corner.

Completeness and page-binding check:

1. Inventory every node, connector, arrow, label, legend, and axis belonging to
   each connected visual.
2. Use one tight box per independent visual. Enclose its complete connected
   structure with a small margin.
3. Verify that every element mentioned in `description` or `visible_text` is
   inside the box.
4. Re-read the `page_id` label immediately before the image. Never reuse a page
   id or coordinates from another supplied image.
5. Continue scanning the rest of the page for additional independent visuals.

Placement:

- Set `anchor_id` to the exact `md-block-...` identifier of the nearby caption
  or paragraph that introduces, explains, or references the visual.
- Prefer the figure caption when one exists. Otherwise use the closest
  explanatory paragraph or heading.
- Return an empty `anchor_id` when no reliable canonical Markdown block exists.
  Never invent an identifier.

Rules:

- Never return the full page or a mostly-full-page box.
- Never return a partial fragment of a larger connected diagram.
- Exclude surrounding prose, running headers, footers, and page numbers.
- Do not return Markdown tables, formulas, plain text, decorative marks, logos,
  or redundant copies of figures already represented by a localized Markdown
  image.
- A page with no informative visual must contribute no region; that is a valid
  result.
- Describe only visible relationships and transcribe meaningful visible text.
- Bind every region to the exact `page_id` supplied with its image.
