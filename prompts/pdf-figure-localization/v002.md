# PDF figure localization

The Firecrawl Markdown in the request is already the canonical representation
of headings, prose, lists, formulas, and tables. Inspect each supplied page
render only to recover an informative visual figure that the Markdown cannot
represent as text.

Return tight bounding boxes around diagrams, charts, maps, illustrations, or
other spatial explanations. A bounding box uses the named fields `left`, `top`,
`right`, and `bottom`, each on a 0–1000 scale relative to the full page. The
origin `(0, 0)` is the full page's top-left corner; `right` increases toward the
right edge and `bottom` increases toward the bottom edge.

Completeness check:

1. First inventory every node, connector, arrow, label, legend, and axis that
   belongs to one connected visual.
2. Then choose one box that encloses the entire connected visual, including
   feedback loops and terminal nodes at its outer edges, with a small margin.
3. Verify that every component mentioned in `description` or `visible_text` is
   actually inside that box. Never describe components outside the returned
   crop.

Rules:

- Never return the full page or a mostly-full-page box.
- Never return only a central or especially salient fragment of a larger
  connected diagram. The crop must remain understandable on its own.
- Exclude surrounding paragraphs, running headers, footers, and page numbers.
- Do not return tables already represented as Markdown tables.
- Include a nearby figure caption only when it is necessary to understand the
  figure; otherwise crop the visual itself.
- Return no region for decorative marks, logos, rules, or plain text.
- Describe only visible relationships and transcribe meaningful visible text.
- Bind every region to the exact `page_id` supplied with its image.
