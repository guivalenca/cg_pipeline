A maquete do juiz

O fluxo inteiro em uma página: 3 geradores de candidatos (semântico, léxico, fechamento) → união + dedupe + teto de ~15 pares por KC unitário → juiz direcional em 4 níveis (duas chamadas por par) → ledger de arestas → resolvedor que devolve KCs compostos, pendências e sinais. Aqui você é o juiz: responde as duas perguntas e assiste a estrutura se formar.

Convenção: A→B significa "dominar A implica dominar B" — a seta sai do avançado e aponta para o básico
0 pares julgados 0 na fila 0 setas duplas 0 setas simples 0 sem relação 0 duplas fracas 0 KCs compostos 0 pendências

Nenhum dado carregado

Esta página não embute mais os dados: ela lê os arquivos JSON que ficam ao lado dela, na pasta reports/. O navegador bloqueia essa leitura quando a página é aberta direto do disco (endereço começando com file://). Duas saídas:

  1. Servir a pasta. No terminal, dentro de reports/, rode python3 -m http.server 8000 e abra http://localhost:8000/grouping-simulator.html. Para carregar uma run do juiz junto: acrescente ?runs=opus5-judge-r0130.json ao endereço.
  2. Arrastar os arquivos. Solte grouping-data.json (o corpus) — e, se quiser, um ou mais arquivos de run do juiz — em qualquer lugar desta página. O botão abaixo faz o mesmo pelo seletor de arquivos.
