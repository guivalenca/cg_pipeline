What Is Settled

Generation Boundary

  • Use extracted markdown plus workbook/index metadata.
  • No separate AI cleaning or annotation in v0.
  • Old runtime graph.json is not a concept-content reference.
  • Workbook defines Lessons and Self-study membership.

Output Boundary

  • Build Graph Artifact keeps audit/provenance metadata.
  • Runtime Graph Export keeps only tutoring content.
  • No day_presets and no runtime self_studies.
  • Promotion to reference/courses/... is manual.

What Is Still For Review

  • Exact run folder layout.
  • Final model/provider routing per stage.
  • Exact Stage Contract JSON schemas.
  • Exact visual/report format for human review.
The main conceptual questions are resolved. These remaining items are implementation-shape decisions.

Pipeline Flow

0. Source Ledger
Inputs
  • cg_pipeline/source/si_mod6.xlsx
  • cg_pipeline/index.json
  • cg_pipeline/extraction/*.md
Job Map Lessons, Self-studies, Source Bodies, unavailable sources, warnings, hashes, and workbook metadata.
Artifacts source_ledger.json
1. Label Interpretation
Inputs Workbook Related Labels from self-study rows.
Job Incrementally classify unseen labels. Active outputs are prerequisite_hint and lesson_cluster.
Artifacts workbook_label_interpretation.json
2. Self-study Extraction
Inputs One Self-study at a time. Source Body when available; workbook metadata when unavailable.
Job Extract Candidate Concepts, Coverage Criteria, Source Roles, Extraction Reasons, Source Anchors, and Source-local Connector Candidates. No order, no dependencies, no cross-source bridges.
Artifacts source_extraction.json per Self-study
3. Top-down Concept Extraction
Inputs Lesson title/description, self-study titles/descriptions, unavailable-source metadata, and lesson-cluster labels.
Job Propose top-down Candidate Concepts from lesson intent. These are weaker than source-body candidates until Lesson Reconciliation accepts them. This stage does not create final Concepts.
Artifacts top_down_concept_extraction.json
4. Lesson Reconciliation
Inputs All valid self-study extractions for one Lesson plus top-down concept candidates.
Job Merge duplicates inside the Lesson, preserve source-grounded material, remove incidental candidates with pruning reasons.
Artifacts lesson_reconciliation.json
5. Story Review
Inputs Lesson draft concepts and lesson intent.
Job Check if the Lesson teaches coherently. Propose Bridge Concepts only when a real gap blocks the teaching flow.
Artifacts pedagogical_story_review.json
6. Subject Merge
Inputs All validated lesson drafts and bridge proposals.
Job Deduplicate across Lessons. Same-Concept Reuse only when Coverage Criteria are compatible. Deeper Revisits become separate Concepts.
Artifacts subject_merge.json
7. Dependency Deferral
Inputs Stable concept inventory from subject_merge.json.
Job Emit an explicit empty edge list. V0 trusts the university Lesson order and defers global prerequisite inference.
Artifacts dependency_inference.json
8. Segmentation And Ordering
Inputs Lesson ID, Lesson title, and stable Lesson Concepts with label, knowledge type, teaching description, and Coverage Criteria.
Job Per Lesson, blind to other Lessons, group Concepts into ordered teaching-flow Segments. Deterministic code adds Segment IDs and instructional_role: "teach".
Artifacts lesson_segments.json per Lesson
9. Critics
Inputs Draft Build Graph Artifact and relevant stage artifacts.
Job Separate critic runs for coverage, granularity, dependencies, pedagogy/segments, and source grounding.
Artifacts critics/*.json
10. Review and Repair
Inputs All critic reports.
Job Conciliatory Review accepts/rejects findings and creates repair plan. Repair routes structural fixes back to the owning stage when possible.
Artifacts conciliatory_review.json
repairs/*
11. Final Assembly
Inputs Accepted repaired Build Graph data.
Job Deterministic only: assign Concept IDs and Display Codes, project dependencies, strip build-only metadata, validate, write outputs.
Artifacts build_graph.json
runtime_graph.json
validation_report.json

Build vs Runtime

Build Graph Artifact Runtime Graph Export
Audit and repair surface. Companion-facing tutoring content.
Includes provenance, evidence type, extraction reasons, source anchors, source roles, pruning decisions, critic/repair summaries. Omits provenance, extraction reasons, evidence type, self-studies, source anchors, and source warnings.
Owns canonical flat dependency edge list, intentionally empty in v0. Has nested prerequisite dependency objects projected deterministically from the flat list, therefore empty in v0.
Can be noisy because humans/validators inspect it. Must be lean because prompts and runtime state consume it.

Validation Posture

Fail fast. If a stage fails its Stage Contract after the allowed format retry, stop the pipeline.

Blockers

  • Invalid Stage Contract output.
  • Usable Self-study lacks extraction or explicit exclusion.
  • Lesson has no Segments.
  • Segment has no Concepts.
  • Concept lacks Coverage Criteria.
  • Missing required runtime concept fields.
  • Invalid dependency type.
  • References to missing Concept IDs.
  • Dependency projection mismatch.
  • Build/runtime disagreement on IDs, Lessons, or Segments.

Not Warnings

  • Empty common_misconceptions.
  • Empty teaching_notes.

Design Safeguards

Metadata-only sources

Unavailable Source Bodies still use title, description, and workbook metadata. They produce the same candidate schema with Evidence Type workbook_metadata. Build artifact keeps that distinction; runtime strips it after validation.

Workbook Related Labels

Incrementally classified. prerequisite_hint is retained for audit and future dependency work. lesson_cluster feeds Top-down Concept Extraction. Application and adjacent-domain labels are recorded and ignored in v0.

Same-concept reuse

A Concept ID can be reused across Lessons only when it is literally the same teachable idea. Coverage Criteria compatibility is the merge test. Deeper Revisits split into separate Concepts.

Format repair

One narrow retry can repair malformed output using the validator error and full failed output. It cannot change graph meaning. If it still fails, stop the pipeline.
